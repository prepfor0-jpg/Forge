# FORGE V3 UNLEASHED

This is based directly on the FORGE V2 UI/architecture and expands it instead of replacing it.

## GitHub Pages
1. Create a repository.
2. Upload all four files to the root.
3. Settings → Pages → Deploy from branch → main → / (root).
4. Open the HTTPS Pages URL on Android Chrome.
5. Choose Install app / Add to Home screen.

The app is local-first: workout/body/activity/readiness data stays in the browser. Export JSON backups regularly.
