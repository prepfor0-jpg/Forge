# FORGE V3

1. Create a GitHub repository (for example `forge-training`).
2. Upload `index.html`, `manifest.webmanifest`, `sw.js`, and `icon.svg` to the repository root.
3. GitHub → Settings → Pages → Deploy from branch → `main` → `/ (root)` → Save.
4. Wait for the Pages URL to become available.
5. Open the HTTPS URL on Android Chrome.
6. Chrome menu → Install app / Add to Home screen.
7. FORGE stores workout/body/activity data locally in the browser. Export JSON regularly.

No backend or database is required.
